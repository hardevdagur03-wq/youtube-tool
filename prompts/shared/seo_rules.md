## SEO Optimization Rules

1. Primary keyword appears in: title, H1, first paragraph, one H2, conclusion
2. Secondary keywords appear in at least 2 H2 sections each
3. Keyword density: primary 0.5-2.0%, secondary 0.3-1.0%
4. Meta description includes primary keyword and a call-to-action
5. URL slug contains primary keyword only
6. Headings follow hierarchy: H1 → H2 → H3 (never skip levels)
7. Image alt text includes keywords naturally
8. Internal links: 3-5 per 1000 words
9. External links: 1-3 to authoritative sources (domain authority 50+)
10. Featured snippet optimization: include definition, list, or step-by-step
11. FAQ schema for 3-5 questions with keyword targeting
12. Target "People Also Ask" questions from search results
13. Reading time: 7-15 minutes for core content
